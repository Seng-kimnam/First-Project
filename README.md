# Profile Page

A simple React profile page demonstrating components, props, and conditional rendering with a `StatusBadge` component.

## Setup

### 1. Clone the repository

git clone https://github.com/Seng-kimnam/First-Project.git

cd <your-project-folder>
### 2. Install module and run it

pnpm install
pnpm run dev

then you got url that run on your local (http://localhost:5173)
